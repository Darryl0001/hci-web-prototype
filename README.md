# Second Look · React prototype

A standalone React, TypeScript, and Tailwind port of the current Flutter app. All comparison data is bundled. Screenshot previews, listing edits, chat, and check history stay in browser memory for the current session.

## Run locally

From this folder, run `npm install` followed by `npm run dev`. Open the local URL Vite prints. `npm run build` type-checks the project and writes the production build to `dist/`.

## Try the sample flows

- Use **Try demo listings** to open the 94% or 76% battery fixtures and compare how the matched listings change.
- Use **Sample screenshot** to follow the bundled ₱22,000 listing from its preview through to evidence and chat. **Sample: shorthand price** exercises price confirmation.
- On a result, open **Ask about this listing** and send “The seller says battery health is 76%.” Review or edit the pending battery value and apply it when ready.
- **Upload screenshot** previews a local image and fills the same sample fields on each upload. **Enter details manually** starts with blank fields.
